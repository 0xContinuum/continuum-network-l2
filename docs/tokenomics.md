# 📊 Tokenomics & NFT Ecosystem

Continuum Network features a dual-asset ecosystem powered by the utility token **$CTM$** and a two-tier **NFT Incentive Infrastructure**.

---

## 1. $CTM$ Token Utility

**$CTM$** is the core functional currency of the Continuum L2 ecosystem.

- **Gasless Threshold:** Holding $\ge 100\ \text{CTM}$ unlocks $0$ ETH gas sponsorship for all network transfers.
- **Deflationary Burn Mechanics:** For every sponsored network transaction, $50\%$ of the accrued gas fee value is permanently burned:
  $$\text{Tokens Burned} = 0.50 \times \text{GasFee}_{\text{CTM}}$$
- **Governance & Staking:** Mainnet $CTM$ will enable validator staking and decentralized protocol voting.
